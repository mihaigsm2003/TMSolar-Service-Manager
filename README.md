# TMSolar Service Manager

A modern PHP-based service management application designed for repair centers and technical service businesses.

## Features

- Customer management
- Service order management
- User authentication
- Admin dashboard
- MySQL database
- Installation wizard
- Automatic configuration
- Activity logging
- Responsive interface

## Requirements

- PHP 8.1+
- MySQL / MariaDB
- Apache or LiteSpeed
- Shared hosting or VPS

## Installation

1. Upload the project to your web server.
2. Create an empty MySQL database.
3. Open:

```
https://your-domain.com/install.php
```

4. Enter your database credentials.
5. Complete the installation.
6. Log in using the default administrator account.

Default credentials:

```
Email: admin@example.com
Password: admin123
```

**Change the default password after your first login.**
